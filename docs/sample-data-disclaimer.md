# Sample-Data Disclaimer

**Every lender, program, guideline version, rule, and scenario shipped with this repository is fictional demonstration data.**

- "Summit Non-QM", "Horizon Alternative Lending", "Atlas Investor Finance", "Evergreen Mortgage Partners", and "Harbor Residential Capital" are invented names. Any resemblance to real companies is coincidental and unintended.
- Every numeric threshold (LTV caps, FICO minimums, DTI limits, seasoning periods, reserve requirements, expense factors) is a structural placeholder — **not** a real lender's guideline, overlay, or offer.
- All records are flagged `isSampleData: true` and the UI displays a persistent label: *"Demonstration program—not a real lender guideline."*
- Sample scenarios use anonymized fictional borrower references (B-1001…) and contain no real personal information.

Administrators must replace sample data with human-verified guidelines through the guideline-versioning workflow (`docs/admin-guide.md`) before relying on any output. Analysis run against sample data is suitable only for demos, development, and testing.
